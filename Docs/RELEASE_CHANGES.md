### 마법자판 난타전 단어 한국어 표시

- 골드 소서 미니게임 **마법자판 난타전**에서 적 머리 위에 표시되는 입력 단어를 한국어로 표시합니다. 한국 서버 클라이언트의 한국어 단어를 같은 행에 그대로 적용합니다.
- 한국 서버 데이터에 한국어가 없는 단어(FF7 리메이크 시리즈 곡명 등, v7.56 기준 일본어 클라이언트 292개·영어 클라이언트 320개)는 패치에 포함된 보충 번역으로 표시합니다. 보충 번역은 공식 번역이 아닙니다. 한국 서버의 같은 시트 표기, FF7 리메이크·리버스 한국어판 표기, FFXIV 한국판 표기를 우선 사용했고, 공식 한국어 곡명은 찾지 못해 곡명 대부분은 직접 번역입니다.
- 보충 번역은 한국어 키보드로 바로 입력할 수 있는 문자(한글, 영숫자, 공백, `, . ! ? - ' &`)만 사용합니다.
- 일본어 클라이언트에서는 한국어 단어의 물결표 `~`를 일본어 단어와 같은 전각 `～`로 바꿉니다. 일본어 클라이언트 입력란은 반각 `~`를 전각으로 입력해 반각 단어와 일치하지 않는다는 보고에 따른 처리입니다.
- **기타 게임 텍스트** 범위입니다. 이 범위를 베이스 언어로 선택하면 단어는 원문을 유지합니다.
- 패치 완료 결과 창에 보충 번역 적용 수와, 한국 서버에 공식 번역이 생겼거나 게임 업데이트로 원문이 바뀐 단어 수를 표시합니다. 원문이 바뀐 단어는 원문을 유지하고 진단 파일에 기록합니다.

### 텍스트를 모두 원문으로 둔 빌드의 로비 한자 보존

- 텍스트를 모두 원문으로 두고 폰트를 포함해 만든 패치에서, 로비 한글 글자 배치가 로그인 대기 문구 등 일본어 로비 문구의 한자를 덮어쓰던 문제를 수정했습니다.
- UI에서 9개 결과(텍스트 8개 범위와 UI 이미지)를 모두 원문으로 고른 **선택 구성 패치**는 이제 폰트만 패치로 생성해 로비 폰트를 바꾸지 않습니다.

**사용 방법**
- 기존 패치를 제거한 뒤, 새 실행 파일에서 **텍스트가 포함된 패치를 다시 생성·적용**해 주세요. 마법자판 난타전 단어는 **전체 한글** 또는 **직접 설정 → 기타 게임 텍스트 → 한국어**일 때 바뀝니다.
- 이미 생성한 패치에는 자동 반영되지 않으며, 폰트 전용 패치로는 단어가 바뀌지 않습니다.

**기타**
- 버그 리포트 양식에 패치 진단 파일과 크래시 자료 첨부 요청을 추가했습니다.

**확인 상태**
- 릴리즈 빌드가 경고 0개·오류 0개로 완료됐고, 배포 EXE에 내장된 제너레이터·폰트 패키지·RSV 맵의 해시가 빌드 입력과 같음을 확인했습니다.
- 보충 번역 회귀 테스트 7개와 내장 보충 번역 시트의 형식·입력 문자 검사를 통과했습니다.
- 공개 v7.56 데이터로 만든 합성 아카이브에서 배포 EXE에 내장된 제너레이터를 실행해, 일본어·영어 대상 모두 단어가 있는 행이 전부 한국어로 바뀌고(보충 번역 일본어 292개·영어 320개, 누락·원문 변경 0개) 일본어 대상의 전각 물결 변환 17개가 적용되며, 기타 게임 텍스트가 베이스 언어면 시트가 바뀌지 않음을 확인했습니다.
- 로비 한자 보존은 clean 텍스트 조사 결과에 해당 문구의 한자가 모두 포함됨을 확인했습니다. clean `000000` 원본 백업이 없어 전체 폰트 재생성과 실제 로비 화면은 확인하지 않았습니다.
- 이번 배포 준비에서는 설치된 게임 폴더를 사용하지 않았습니다. 실제 게임에서의 단어 표시와 입력 인식(전각 물결 포함)은 별도 확인이 필요합니다.
