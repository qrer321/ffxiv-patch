### 마법자판 난타전 물결표 단어 입력 수정

- 일본어 클라이언트에서 물결표(`~`)가 든 한국어 단어를 그대로 입력해도 정답으로 인정되지 않던 문제를 수정했습니다. 지난 버전은 이 단어들의 물결표를 일본어 단어와 같은 전각 `～`로 바꿨는데, 한국어 자판으로 입력하는 물결표는 반각 `~`라 서로 맞지 않았습니다.
- 이제 일본어·영어 클라이언트 모두 한국 서버 단어와 같은 반각 `~`를 씁니다(v7.56 기준 17개 단어). 영어 클라이언트는 지난 버전과 같습니다.
- 한글 입력기를 전각(전자) 모드로 두면 물결표가 전각으로 입력돼 이 단어들이 인정되지 않습니다. 입력기를 반각(반자) 모드로 두고 입력해 주세요.

**사용 방법**
- 새 실행 파일에서 **텍스트가 포함된 패치를 다시 생성·적용**해 주세요. 이미 생성한 패치에는 반영되지 않습니다.

**확인 상태**
- 릴리즈 빌드가 경고 0개·오류 0개로 완료됐고, 배포 EXE에 내장된 제너레이터·폰트 패키지·RSV 맵의 해시가 빌드 입력과 같음을 확인했습니다.
- 보충 번역 회귀 테스트 6개와 내장 보충 번역 시트 검사를 통과했습니다.
- 공개 v7.56 데이터로 만든 합성 아카이브에서 내장 제너레이터를 실행해, 일본어·영어 모두 단어가 전부 한국어이고 물결표가 든 17개 단어가 반각 `~`이며 전각 `～`가 든 단어가 없음을 확인했습니다.
- 이번 배포 준비에서는 설치된 게임 폴더를 사용하지 않았습니다. 반각 `~` 단어의 실제 게임 입력 인식은 별도 확인이 필요합니다.

물결표 입력 문제를 제보해 주신 분께 감사드립니다.
