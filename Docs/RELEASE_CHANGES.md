### 패치 제거·백업 복구 결과에 이전 버전 index 안내 추가

- 게임 업데이트 뒤 **패치 제거**나 **백업으로 복구**를 하면, 저장해 둔 index 중 게임 버전이 달라 덮어쓰지 않은 파일을 결과 창에 `그대로 둔 파일`로 표시합니다. 이 파일들은 업데이트로 새로 받은 index이며, 그대로 두는 것이 정상입니다.
- 되돌릴 원본이 다른 게임 버전의 index뿐이면, 지금까지는 "처리되지 않은 예외" 창이 떴습니다. 이제 "클라이언트 파일은 바꾸지 않았습니다"라는 경고 창으로 바뀌고, 런처 파일 검사/복구를 안내합니다. 클라이언트 파일을 바꾸지 않는 것은 이전 버전과 같습니다.
- 복구할 백업이 없다는 안내에 "설치된 index와 게임 버전이 다른 백업은 복구에 쓰지 않습니다"를 추가했습니다.
- 게임 업데이트 없이 패치 제거를 하면 결과 창은 지금과 같습니다.

**사용 방법**
- 게임 업데이트 뒤에는 지금처럼 **패치 제거 → 패치** 순서로 진행해 주세요. 결과 창의 `그대로 둔 파일`은 조치할 필요가 없습니다.
- 경고 창이 런처 파일 검사/복구를 안내하면, 런처에서 복구한 뒤 다시 패치해 주세요.

**확인 상태**
- 릴리즈 빌드가 경고 0개·오류 0개로 완료됐고, 배포 EXE에 내장된 제너레이터·폰트 패키지·RSV 맵의 해시가 빌드 입력과 같음을 확인했습니다.
- 실제 7.58 index 파일로 만든 가상 설치 폴더에서 결과 창을 확인했습니다. 업데이트 뒤 패치 제거, 업데이트 없이 패치 제거, 업데이트 뒤 백업으로 복구, 맞는 원본이 없는 패치 제거, 복구할 백업이 없는 경우입니다.
- 실제 게임 업데이트를 받은 클라이언트와 실제 게임에서의 확인은 하지 않았습니다.
