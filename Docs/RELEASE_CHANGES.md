### 변형 던전 주문도 베이스 언어로 입력

- **말하기 퀘스트 입력 문구**를 베이스 언어(기본값)로 두면, 변형 던전 숨겨진 루트에서 채팅 `말하기`로 외우는 주문도 일본어·영어 원문으로 입력합니다. 지금까지는 이 주문이 한국어로 바뀌어 있어 원문으로 외우면 루트가 열리지 않고 한국어로만 통했습니다.
  - 알로알로 섬: 문조·바다거북·고래 조각상 앞 주문 3개
  - 상인 이야기: 바닷가에서 부르는 주문 1개
- 탐색 수첩과 던전 안 글귀의 한국어 주문 뒤에 원문을 함께 표시합니다. 예: `"하늘을 나는 신이여(O dancer of the skies, hear me.)"`. 영어 주문은 일본어를 그대로 옮긴 말이 아닐 수 있으니 괄호 안 원문을 그대로 입력해 주세요.
- 설정을 `한국어`로 두면 지금처럼 한국어 주문으로 입력합니다.

**사용 방법**
- 새 실행 파일에서 **텍스트가 포함된 패치를 다시 생성·적용**해 주세요. 이미 생성한 패치에는 반영되지 않습니다.

**확인 상태**
- 릴리즈 빌드가 경고 0개·오류 0개로 완료됐고, 배포 EXE에 내장된 제너레이터·폰트 패키지·RSV 맵의 해시가 빌드 입력과 같음을 확인했습니다.
- 말하기 퀘스트 회귀 테스트 26개(주문·안내 처리 3개 추가)를 통과했습니다.
- 공개 데이터의 해당 행으로 만든 합성 아카이브에서 내장 제너레이터를 실행해, 일본어·영어 대상 모두 주문 4개가 원문으로 남고 안내 4곳에 원문이 표시되며, `한국어` 설정에서는 지금과 같음을 확인했습니다. 스토리 검증기도 같은 결과를 기대값으로 통과했습니다.
- 주문 행은 안내문에 인용된 문구와 글자가 같은 행을 찾아 정했습니다. 실제 게임에서 이 행과 비교하는지는 게임 스크립트로 확인하지 않았고, 한국어 주문만 통한다는 제보와 행 내용으로 판단했습니다.
- 이번 배포 준비에서는 설치된 게임 폴더를 사용하지 않았습니다.

알로알로 섬 주문 문제를 제보해 주신 분께 감사드립니다.
