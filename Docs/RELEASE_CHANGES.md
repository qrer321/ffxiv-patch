### 마법자판 난타전 단어 한국어화

- 골드 소서 미니게임 **마법자판 난타전**에서 적 머리 위에 뜨는 단어를 한국어로 표시합니다. 한국 서버에 있는 한국어 단어를 그대로 사용합니다.
- 한국 서버에도 일본어로 남아 있는 단어(FF7 리메이크 시리즈 곡명 등)와 영어 클라이언트에만 있는 단어는 패치에 포함된 보충 번역으로 표시합니다(v7.56 기준 일본어 클라이언트 292개, 영어 클라이언트 320개). 보충 번역은 공식 번역이 아니며, 한국 서버·FF7 리메이크 시리즈 한국어판·FFXIV 한국판 표기를 우선 따랐습니다. 공식 한국어 곡명은 찾지 못해 곡명은 대부분 직접 번역했습니다.
- 보충 번역 단어는 한국어 키보드로 바로 입력할 수 있는 한글·영숫자·공백과 `, . ! ? - ' &`만 씁니다. 물결표 `~`는 한국 서버 문구를 그대로 가져온 단어에만 있습니다.
- 일본어 클라이언트에서는 단어의 물결표를 일본어 단어와 같은 전각 `～`로 바꿉니다. 일본어 입력란에서 `~`가 전각으로 입력돼 단어와 맞지 않는다는 제보에 따른 처리입니다.
- **기타 게임 텍스트**를 베이스 언어로 선택하면 단어는 원문 그대로입니다.
- 게임 업데이트로 원문이 바뀐 단어는 보충 번역 대신 원문을 표시하고, 패치 완료 결과 창에 그 수를 표시합니다.

### 로비 한자 표시 수정

- 텍스트를 모두 원문으로 두고 한글 폰트를 포함해 만든 패치에서, 로그인 대기 안내 등 로비 일본어 문구의 일부 한자가 한글 글자에 덮어써져 잘못 표시되던 문제를 수정했습니다.
- 9개 결과를 모두 원문으로 고른 **선택 구성 패치**는 이제 폰트만 패치로 만들어 로비 폰트를 바꾸지 않습니다.

**사용 방법**
- 기존 패치를 제거한 뒤, 새 실행 파일에서 **텍스트가 포함된 패치를 다시 생성·적용**해 주세요. 마법자판 난타전 단어는 **전체 한글** 또는 **직접 설정 → 기타 게임 텍스트 → 한국어**일 때 바뀝니다.
- 이미 생성한 패치에는 자동 반영되지 않으며, 폰트 전용 패치로는 단어가 바뀌지 않습니다.

**기타**
- 버그 리포트 양식에 패치 진단 파일과 크래시 자료 첨부 요청을 추가했습니다.

**확인 상태**
- 릴리즈 빌드가 경고 0개·오류 0개로 완료됐고, 배포 EXE에 내장된 제너레이터·폰트 패키지·RSV 맵의 해시가 빌드 입력과 같음을 확인했습니다.
- 보충 번역 회귀 테스트 7개와 내장 보충 번역 시트의 형식·입력 문자 검사를 통과했습니다.
- 공개 v7.56 데이터로 만든 합성 아카이브에서 내장 제너레이터를 실행해, 일본어·영어 모두 단어가 전부 한국어로 바뀌고 일본어 대상의 전각 물결 변환 17개가 적용되며, 기타 게임 텍스트가 베이스 언어면 단어가 바뀌지 않음을 확인했습니다.
- 로비 한자 수정은 clean 텍스트 조사 결과에 해당 한자가 모두 포함됨을 확인했고, 실제 로비 화면은 확인하지 않았습니다.
- 이번 배포 준비에서는 설치된 게임 폴더를 사용하지 않았습니다. 실제 게임에서의 단어 표시와 입력 인식(전각 물결 포함)은 별도 확인이 필요합니다.
