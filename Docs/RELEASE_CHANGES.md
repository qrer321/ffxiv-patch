### 마법자판 난타전 한국 서버 단어 오타 보정

- 한국 서버 원문에 있는 오타 6개를 바로잡아 표시합니다. 화면에 보이는 단어를 그대로 입력하면 되는 것은 같습니다.
  - `모그리다` → `모그리`
  - `중갑장 전투원` → `중장갑 전투원`
  - `미스릴 컬러` → `미스릴 칼라`
  - `헤븐스 트라이블` → `헤븐스 트라이벌`
  - `사기 호흡` → `사기 흡수`
  - `기잘 야채 줘!` → `기살 야채 줘!`
- 한국 서버가 나중에 이 단어를 고치거나 바꾸면 보정을 멈추고 한국 서버 문구를 그대로 씁니다.
- 패치 완료 결과 창에 오타 보정 수를 표시합니다.

**사용 방법**
- 새 실행 파일에서 **텍스트가 포함된 패치를 다시 생성·적용**해 주세요. 이미 생성한 패치에는 반영되지 않습니다.

**확인 상태**
- 릴리즈 빌드가 경고 0개·오류 0개로 완료됐고, 배포 EXE에 내장된 제너레이터·폰트 패키지·RSV 맵의 해시가 빌드 입력과 같음을 확인했습니다.
- 보충 번역 회귀 테스트 7개와 내장 보충 번역 시트 검사를 통과했습니다.
- 공개 v7.56 데이터로 만든 합성 아카이브에서 내장 제너레이터를 실행해, 일본어·영어 모두 6개 단어가 보정되고 단어가 전부 한국어이며, 기타 게임 텍스트가 베이스 언어면 단어가 바뀌지 않음을 확인했습니다.
- 오타 판단은 같은 시트의 다른 단어, FFXIV 한국판 표기, FF7 리메이크 한국어판 표기를 근거로 했습니다. 의도된 표기일 수 있는 후보는 보정하지 않았습니다.
- 이번 배포 준비에서는 설치된 게임 폴더를 사용하지 않았습니다.
