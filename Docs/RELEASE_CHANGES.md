### 말하기 퀘스트를 베이스 언어 원문으로 진행

- 채팅 `/say`로 정해진 문구를 입력하는 퀘스트에서 일본어·영어 원문을 입력하도록 선택할 수 있습니다. 글로벌 서버의 다른 플레이어에게 한글 채팅이 깨져 보이는 문제를 피하기 위한 기능입니다.
- 퀘스트 설명과 일반 대사는 한국어로 유지하고, 실제 정답 문구만 선택한 베이스 언어 원문으로 유지합니다. 한국어 목표·일지·안내에는 `힘내!(がんばれ)`처럼 입력할 원문을 함께 표시합니다.
- 영어 베이스에서는 영어 정답을 사용합니다. 일본어 안내는 정답 행을 찾는 참조로 사용하며, 영어 정답을 일본어로 바꾸지는 않습니다.
- 추리형 퀘스트에서도 대사·수수께끼에 등장하는 정답 문구에 원문 철자를 덧붙입니다. 정답 단어에만 원문이 붙어 기존보다 힌트가 명확해질 수 있습니다.
- UI에 **말하기 퀘스트 입력 문구** 선택을 추가했습니다. 기본값은 베이스 언어이며, 선택은 저장되고 텍스트 구성 전환과 별개로 유지됩니다. 스토리·퀘스트 텍스트 자체가 베이스 언어면 선택이 비활성화됩니다.

**사용 방법**
- 기존 패치를 제거한 뒤, 새 실행 파일에서 베이스 언어와 말하기 퀘스트 입력 문구를 선택하고 **텍스트가 포함된 패치를 다시 생성·적용**해 주세요.
- 원문 모드에서는 안내의 괄호 안 원문만 채팅창에 입력합니다. 한국어와 원문을 동시에 정답으로 받는 기능은 아닙니다.
- 이미 생성한 패치에는 자동 반영되지 않으며, 폰트 전용 패치로는 정답 문구가 바뀌지 않습니다.
- CLI는 기존 출력 호환성을 위해 기본값이 `ko`입니다. 원문 모드는 `--say-quest-phrases base`로 지정합니다.

**안전 처리와 검증기 개선**
- 정답에 매크로가 있거나 비어 있거나 너무 길어 안전하게 처리할 수 없으면 해당 퀘스트는 한국어로 유지합니다.
- 안내형 퀘스트는 필요한 원문을 모두 표시할 수 있어야 변환합니다. 같은 한국어 문구가 여러 원문에 대응하는 경우에도 원문별로 확인하며, 하나라도 안내할 수 없으면 한국어로 유지합니다.
- 스토리 검증기가 플레이어 호칭 변환과 말하기 문구 처리를 생성기와 같은 기준으로 반영하도록 개선했습니다.
- 한국어 원본이 없는 폴백 셀의 원문 표기도 검증하며, 읽을 수 없는 선택적 일본어 참조는 대상 언어 페이지로 폴백합니다.

**확인 상태**
- 릴리즈 빌드가 경고 0개·오류 0개로 완료됐습니다.
- 말하기 퀘스트 회귀 테스트 23개와 플레이어 호칭 회귀 테스트 21개를 통과했습니다.
- 배포 EXE에 내장된 제너레이터·폰트 패키지·RSV 맵의 해시, 실제 추출과 삭제된 payload의 재추출을 확인했습니다.
- 실제 배포 UI의 새 선택 항목, 일본어·영어 라벨, 스토리 베이스 전환에 따른 비활성화·재활성화를 확인했습니다.
- 내장 제너레이터의 합성 아카이브 실행으로 일본어·영어 원문 입력, 한국어 모드와 CLI 기본값, 안전 폴백, 스토리 베이스 유지 및 정답 바이트·행 ID·키 보존을 확인했습니다.
- 이번 배포 준비에서는 설치된 게임 폴더를 사용하지 않았습니다. 실제 게임 전체 퀘스트 진행, 말풍선 버튼, 자동 사전 점검·실제 클라이언트 적용은 별도 확인이 필요합니다.
